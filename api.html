Models¶

Interpretable models for bounded content sequences.

class contentsequence.models.LinearSinusoidalModel(sequence_bounds=(0.0, 100.0))[source]¶

Bases: GenericPolynomialSinusoidalModel

Fit the paper’s linear-sinusoidal content-sequence model.

The latent mean is

c + m*t + a*sin(2*pi*f*t - phase).

Default priors scale with sequence_bounds. For bounds (0, 100), the linear intercept has mean 50 and standard deviation 25, the linear trend has standard deviation 25, amplitude is TruncatedNormal(10, 5), and observation scale is HalfNormal(10). Frequency and phase retain the paper-oriented defaults of TruncatedNormal(1.5, 0.3) and VonMises(0, 5).

Parameters:

sequence_bounds (Tuple[float, float]) – Finite lower and upper bounds for the observed sequence measure.

Notes

The model records opening_position, opening_direction, linear_trend, minimum_location, and maximum_location as deterministic posterior variables.

class contentsequence.models.QuadraticModel(sequence_bounds=(0.0, 100.0))[source]¶

Bases: GenericPolynomialSinusoidalNormalModel

Fit a quadratic trend with a bounded Normal likelihood.

The latent mean is c + m*t + q*t**2. Default coefficient and likelihood priors scale to sequence_bounds.

Parameters:

sequence_bounds (Tuple[float, float]) – Finite lower and upper bounds for the observed sequence measure.

Notes

The model records opening position and direction plus global minimum and maximum locations on [0, 1]. Endpoints and an in-range vertex are considered. CurvilinearModel is an alias for this class.

class contentsequence.models.LinearModel(sequence_bounds=(0.0, 100.0))[source]¶

Bases: GenericPolynomialSinusoidalNormalModel

Fit a linear trend with a bounded Normal likelihood.

The latent mean is c + m*t. Default coefficient and likelihood priors scale to sequence_bounds.

Parameters:

sequence_bounds (Tuple[float, float]) – Finite lower and upper bounds for the observed sequence measure.

Notes

The model records opening position and direction. Its global extrema occur at the endpoints; when the slope is exactly zero, both locations are zero.

class contentsequence.models.ConstantModel(sequence_bounds=(0.0, 100.0))[source]¶

Bases: GenericPolynomialSinusoidalNormalModel

Fit a constant mean with a bounded Normal likelihood.

The latent mean is c. The default linear intercept and likelihood priors scale to sequence_bounds.

Parameters:

sequence_bounds (Tuple[float, float]) – Finite lower and upper bounds for the observed sequence measure.

Notes

The model records opening position and a zero opening direction. Minimum and maximum locations are undefined for a constant sequence and are not stored.

class contentsequence.base_models.StudentTLikelihoodModel(*args, likelihood_priors=None, **kwargs)[source]¶

Bases: LikelihoodModel

Mixin that adds a bounded Student-t observation likelihood.

The default observation-scale prior is a half-Normal with standard deviation equal to one tenth of sequence_range. Degrees of freedom follow 2 + Exponential(scale=10), which has mean 12 and keeps support above 2.

class contentsequence.base_models.GenericPolynomialSinusoidalBaseModel(N, M, sequence_bounds=(0.0, 100.0))[source]¶

Bases: BaseModel

Shared polynomial-sinusoidal mean model without a fixed likelihood.

N is the polynomial degree, so the trend has N + 1 coefficients. M is the number of sinusoidal harmonics. Default priors scale to sequence_bounds: the linear intercept is centered on the range midpoint, while polynomial changes and sinusoidal amplitudes are expressed as fractions of the range.

Parameters:

  • N – Non-negative polynomial degree.

  • M – Non-negative number of sinusoidal harmonics.

  • sequence_bounds (Tuple[float, float]) – Finite lower and upper observation bounds.

class contentsequence.priors.ScaleScalarPrior(scale, lower=None, upper=None)[source]¶

Bases: object

Parameters for a shifted, optionally bounded Exponential prior.

This prior is used for the Student-t degrees of freedom. scale is the mean Exponential excess above lower; equivalently, its rate is 1 / scale.
